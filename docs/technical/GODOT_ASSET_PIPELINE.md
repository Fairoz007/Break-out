# Godot asset pipeline

Phase01 specification, not an implemented pipeline. Existing root project.godot declares feature4.7, Forward Plus, Jolt and Windows D3D12; those configuration strings do not prove an installed stable release. Preserve existing project. The coordinator verified installed Godot4.7.2.stable.steam.ed1daf0bf and recorded import/preview evidence in [validation report](../assets/ASSET_VALIDATION_REPORT.md). Pin that verified version for continuation; do not silently downgrade project metadata. The numbered workflow below is the production process, not a claim that all required assets passed it.

1. Inventory requirements against scene/mission IDs. Check existing files before acquisition. Source only authorized commercial-use files with license evidence; record author, source page, direct download URL and retrieval date.
2. Keep exact original bytes in asset_library/original_downloads; compute SHA-256 before extraction. Save license text/page evidence under licenses. Inspect archive listing for path traversal, executables and unexpected dependencies before extracting to asset_library/extracted_sources/asset_id. Never execute bundled tools.
3. Prefer glTF2 .glb for skeletal/static meshes and animation; PNG/JPEG source maps; WAV/OGG audio. Preserve original FBX/Blend if acquired. Convert only through documented available exporter with version, options and source checksum recorded; do not rename extensions. Converted derivatives go converted/asset_id, not original_downloads.
4. Godot unit1m, +Y up, -Z character forward. Use explicit export transforms and apply scale before rig binding; test reference 1m cube and 1.8m adult, then verify orientation visually. Names lowercase snake_case runtime; stable manifest IDs remain uppercase. Avoid spaces, case-only renames and absolute external texture paths.
5. PBR: albedo sRGB, metallic/roughness/normal linear; verify normal-map convention by lit sphere/render, not filename. Track channel packing and AO separately; no invented material resolution. 2K general surfaces/4K hero requirements are budget proposals, not proof of quality. Avoid duplicate textures in per-character copies.
6. Runtime files under assets/category/asset_id/. Keep .glb and dependent textures together with relative references. Godot import sidecars belong with source if policy permits; generated .godot cache remains excluded. External source/library archives must be excluded from engine import with .gdignore at library root so they are not duplicated in exports.
7. Import in editor or pinned headless executable with --headless --path PROJECT --editor --import. Capture exact command, executable version, exit code and log. A successful import is only resource loading evidence, not visible quality or animation deformation PASS. Test dedicated non-gameplay validation scene only when authorized in next phase; Phase01 may use isolated temporary previews without gameplay code.
8. Validate mesh surface counts, triangles, bounds, material slots, texture paths and rig bones with available parsers. Inspect actual rendered poses and motion before visual/skeleton/foot-slide PASS. Missing renderer/exporter means BLOCKED or NOT TESTED. Audio check decoded duration/peak plus listening where available; metadata alone cannot pass audible clipping.
9. Record each criterion as PASS/FAIL/BLOCKED/NOT TESTED with evidence path and checksum. Never promote requirement-only record to downloaded. Rejected items stay rejected/ with reason/license; do not include in runtime.

Godot scene wrapper convention: asset_id_visual.tscn wraps imported visual; gameplay collision/interactions belong in authored scenes, not inside regenerated source. No wrapper scenes have been created by this document.
