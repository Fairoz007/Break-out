# Chapter 1 asset coverage matrix — Phase 01.5

Generated by `tools/phase15_coverage.py` from [assets.json](../../asset_library/manifests/assets.json) and `asset_library/manifests/phase15/integration_summary.json`. Every ID resolves in the manifest unless marked MISSING. **Functional** = a usable, Godot-loading asset exists (realistic, proxy or construction-grade). **Production** = meets the intended realistic/cinematic standard; tracked separately and never closed by a functional substitute. CRITICAL = needed to play/stage the mission; IMPORTANT = intended presentation; OPTIONAL = dressing that never blocks implementation.

Status words: AVAILABLE (usable asset, PARTIALLY_VERIFIED: loads and renders; collision/nav/listening not tested), FUNCTIONAL (realistic candidate verified for functional use), FUNCTIONAL_PROXY (stand-in only), PARTIAL (some subcomponents missing), MISSING.
