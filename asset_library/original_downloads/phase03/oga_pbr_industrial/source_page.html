This is an edit of rubberduck's High Quality Industrial Asset Pack to use PBR materials and the modern Blender 4.0 save format.

Features:

  • Variety of industrial models and materials, including tanks, pipes, staircases, control panels, containers, and more
  • Reorganized file structure to make further edits easier
  • Modern PBR materials with metallicity, roughness, and normal maps
  • Modern Blender save file format

Caveats:

  • As specular maps cannot be directly converted to metallicity and roughness, not all materials look the same as the original.
  • I haven't modified the baked versions of any of the models, as I don't need them for my own projects. This means that they're missing metallic and roughness maps.
  • Furthermore, any changes applied to materials post-bake by the original author were not applied to the pre-bake versions in this project. The building with three big tanks, for example, has gray tanks instead of the baked version's red.
