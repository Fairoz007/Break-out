# Adobe Mixamo usage evidence

Verified 19 October 2026. Official FAQ: https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html

Adobe permits royalty-free commercial video-game use of characters and animations. No CC0 or open redistribution license is inferred. Raw FBX/GLB source assets are kept as internal project dependencies and must not be marketed or published as an asset library.

The default animation reference character is not Adrian Cross, Noah Reyes or an approved final NPC. Each clip still requires retargeting and gameplay/cinematic contact review.
